Personal Decision & Problem Solver

Decide better, every day.

One app for your decisions, tasks, money, habits and study — built by a three-person team in C++, with a web dashboard that reads and writes the exact same data files as the console app. No fake data, no demo numbers: what you see is what you saved.

First registered user becomes ADMIN. Runs on your own computer (localhost only) — your data stays in plain-text files in your data directory, and can be backed up with one click.

🧠 Decide

Daily decisions, priority scores, task prioritization, compare options, multi-task planning, deadline alerts and plain-language explanations.

💰 Manage money

Budget, income and expense, savings goals, weekly and monthly reports, and TXT/CSV export of your real transactions.

📖 Build habits

Habit tracking with a true consecutive-day streak, study planner, time allocation, and a daily summary report.

How it works

  1. Register — the first account is ADMIN, later accounts are USER.
  2. Log in — you get a session token; it is never your password, and it is never written to a file.
  3. Use any section — every button calls a real C++ API endpoint, and every change is saved to a plain-text file the console app can also read.
  4. Back up — Overview has Backup and Restore for your decision records.

Team

Rifat — system core, authentication, profile, admin, password, time allocation, study planner, dashboard and C++ backend. Nuriya — daily decision, priority, tasks, compare, status, deadlines, explanations, multi-task. Sweety — budget, income/expense, savings, habits, streak, reports, export.

Search & History

Searches the same decisions.txt the C++ app reads (menu 28–32: history, search, filter, sort). Type a keyword to filter; sort by priority to see what matters most.

Error Log (menu 33)

Same as the C++ Show Error Log: lines from error_log.txt. Log messages never contain passwords.

Daily Decision

Same logic as the C++ Daily Decision Maker (menu 9), and the result is saved as a Daily decision record.

Multi-Task Daily Decision (menu 43)

Tasks are sorted by deadline urgency, then accepted only while their energy and time both fit the remaining budgets — the restored Sweety algorithm.

Task Management

Tasks are scored exactly like the C++ Task Prioritization: score = urgency × 2 + importance × 3, sorted highest first. Note: the C++ task list is in-memory only, so the dashboard persists tasks in tasks.txt (see dashboard/README.md).

Task Status

Same statuses as the C++ Task Status Manager: Pending, In Progress, Completed. Changing a status here updates the same tasks.txt that Task Management uses.

Priority Calculator

Same formula and levels as the C++ Priority Calculator (menu 10): score = urgency × 2 + importance × 3, out of 50.

Decision Explanation

Same explanation as the C++ Decision Explanation module: the formula, the exact calculation, and what the score means.

Deadline Alerts

Same alerts as the C++ Deadline Alert module: OVERDUE, DUE TODAY, UPCOMING. Completed tasks are skipped. Leave the date blank to use today.

Budget Decision

Same decision as the C++ Budget Decision (menu 37).

Income / Expense

Transactions are written to transactions.txt in the C++ format: date|type|category|amount|note.

Savings

Goals are stored in savings_goals.txt as name|target|saved, exactly like the C++ app.

Savings Goal Calculator (menu 39)

Same as the C++ Savings Goal calculator: remaining amount and estimated months. Not saved as a goal — a calculation, like the console module.

Study Planner

Same plan as the C++ Study Planner: one line per day, total hours = days × hours per day. This plan is calculated, not saved — like the console module.

Time Allocation

Same check as the C++ Time Allocation module: the four values must each be 0–24, and the total is compared with 24 hours.

Habit Tracker

Completions go to habit_log.txt as habit|date. The streak is the true consecutive-day streak from the Phase 1 backend fix, not just a total count.

Habit Decision (menu 40)

Same as the C++ Habit Decision: completion percentage and message. Not saved — a calculation, like the console module.

Habit Streak Calculator (menu 41)

Same as the C++ Habit Streak calculator: previous consecutive days plus today (yes/no). This is different from the true streak above, which is computed from habit_log.txt dates.

Reports

Weekly reports cover the 7 days ending on the given date; monthly reports cover the given YYYY-MM month — the same filtering as the C++ period reports.

Daily Summary Report (menu 36)

Same as the C++ Daily Summary: balance = income − expenses, habit rate = completed × 100 / planned, appended to daily_report.txt.

Export TXT / CSV (menus 26–27)

Same content as the C++ TXT/CSV export of transactions.txt, and the same files (financial_report.txt / .csv) are written in the data directory. Download starts in your browser.

Compare Options

Same formula as the C++ Compare Options (menu 12, Nuriya): score = benefit × 3 − cost − risk, each 1–10. This comparison is not saved as a decision, like the console module.

Problem Solver

Same logic as the C++ Problem Solver (menu 35, Sweety): difficulty 1–5 and available time decide the suggestion, and it is saved as a Problem decision record.

Admin Panel

Same information as the C++ Admin Panel (menu 5, Rifat): registered users with username and role only. Never passwords. Only an ADMIN can open this section; other users see an access message.

User Profile

Same information as the C++ Profile screen: username and role. Admins also see the registered user list (usernames and roles only, never passwords).

Analytics

Charts drawn only from your saved data — monthly income vs expense from transactions.txt, and savings progress from savings_goals.txt. No demo or placeholder data.
