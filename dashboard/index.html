Overview

A live summary of your decisions, tasks, money and habits.

Recent decisions

Search & History

Searches the same decisions.txt the C++ app reads (menu 28–32: history, search, filter, sort). Type a keyword to filter; sort by priority to see what matters most.

Daily Decision

Same logic as the C++ Daily Decision Maker (menu 9), and the result is saved as a Daily decision record.

Multi-Task Daily Decision (menu 43)

Tasks are sorted by deadline urgency, then accepted only while their energy and time both fit the remaining budgets — the restored Sweety algorithm.

Task Management

Tasks are scored exactly like the C++ Task Prioritization: score = urgency × 2 + importance × 3, sorted highest first. Note: the C++ task list is in-memory only, so the dashboard persists tasks in tasks.txt (see dashboard/README.md).

Task Status

Same statuses as the C++ Task Status Manager: Pending, In Progress, Completed. Changing a status here updates the same tasks.txt that Task Management uses.

Priority Calculator

Same formula and levels as the C++ Priority Calculator (menu 10): score = urgency × 2 + importance × 3, out of 50.

Decision Explanation

Same explanation as the C++ Decision Explanation module: the formula, the exact calculation, and what the score means.

Deadline Alerts

Same alerts as the C++ Deadline Alert module: OVERDUE, DUE TODAY, UPCOMING. Completed tasks are skipped. Leave the date blank to use today.

Budget Decision

Same decision as the C++ Budget Decision (menu 37).

Income / Expense

Transactions are written to transactions.txt in the C++ format: date|type|category|amount|note.

Savings

Goals are stored in savings_goals.txt as name|target|saved, exactly like the C++ app.

Study Planner

Same plan as the C++ Study Planner: one line per day, total hours = days × hours per day. This plan is calculated, not saved — like the console module.

Time Allocation

Same check as the C++ Time Allocation module: the four values must each be 0–24, and the total is compared with 24 hours.

Habit Tracker

Completions go to habit_log.txt as habit|date. The streak is the true consecutive-day streak from the Phase 1 backend fix, not just a total count.

Reports

Weekly reports cover the 7 days ending on the given date; monthly reports cover the given YYYY-MM month — the same filtering as the C++ period reports.

User Profile

Same information as the C++ Profile screen: username and role. Admins also see the registered user list (usernames and roles only, never passwords).

Settings

Theme is saved in this browser only. Password change uses the same rules as the C++ password change: current password must match, new password needs 8+ characters, a letter and a digit.
